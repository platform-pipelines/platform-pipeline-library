# Unversioned on purpose: jenkins-plugin-cli resolves one mutually-compatible
# set of latest versions against the pinned Jenkins core in the Dockerfile,
# rather than a hand-picked set of versions that drift out of sync with each
# other over time (that's what broke this image before — see git history).
# Bump the Jenkins core version in a PR, rebuild, run the library test suite
# against the new image, then promote. Never install through the UI.
